    Project Insight

    Project Insight turns raw scene data and playtest telemetry into actionable dashboards inside the Unity Editor. Track KPIs, catch performance spikes, and share reports without leaving your workflow.

    Get it on the Asset Store See the dashboards

    Version highlights

    • 1.1 – Live playtest telemetry, KPI thresholds, CSV export.
    • 1.0 – Scene complexity scoring, lighting budget tracker, collaborative notes.
    • 0.9 – Build size diffs, mesh & material audits, profiler bookmarks.

    Compatibility

    Supported Unity versions: 2021.3 LTS – 2023.2. Tested on Windows & macOS.

    Optional scripting define PROJECT_INSIGHT_TELEMETRY enables advanced data capture helpers.

    Dashboards at a glance

    Each dashboard ships with sample data, quick-start guides, and workflow callouts so you can tailor Insight to your studio.

    Scene overview

    Complexity dashboard

    Instantly see draw calls, mesh density, light counts, and shader usage per scene with auto-generated red flags for problem areas.

    Playtest tracker

    Stream anonymous session data from dev builds and visualize retention, difficulty spikes, and heatmap density in real time.
