    Key features

    Built for simplicity, security, and speed.

    Password generator

    Create randomized passwords with custom length and character sets including uppercase, lowercase, numbers, and symbols.

    Encrypted vault

    Save passwords locally with labels like “Steam”, “Email”, or “WiFi”. Unlock with your master password to view entries.

    Instant search & list view

    Search by name or scan every saved entry with a scrollable “Show All” mode.

    Offline by design

    NeoLock never connects to the internet. No analytics, telemetry, or cloud syncing.

    Portable utility

    Runs as a standalone app on Windows, macOS, and Linux. Keep it on a USB drive if you want.

    Security notice

    If you forget your master password, your data cannot be recovered. This is intentional and part of the security model.

    Privacy-first approach

    Everything stays local on your device.

    No servers, no tracking

    NeoLock never sends data anywhere. The password database lives as passwords.dat on your machine.

    Master password protection

    If someone copies your vault file, they cannot decrypt it without your key. Keep your master password safe.

    Install & open NeoLock

    Step-by-step instructions for each platform.

    Windows

    1. Download NeoLock_Windows_v1.0.0.zip.
    2. Extract the ZIP (Right-click → Extract All…).
    3. Open the folder and double-click NeoLock.exe.
    4. (Optional) Right-click NeoLock.exe → Create shortcut.

    Linux

    1. Download NeoLock_Linux_v1.0.0.zip.
    2. Extract the ZIP (Right-click → Extract Here or run unzip NeoLock_Linux_v1.0.0.zip).
    3. Make the app executable: chmod +x NeoLock.x86_64.
    4. Run ./NeoLock.x86_64 and the window opens.

    macOS

    1. Download NeoLock_macOS_v1.0.0.zip and double-click to extract.
    2. Move NeoLock.app wherever you like (Applications recommended).
    3. First launch: right-click NeoLock.app → Open, then click Open on the prompt.
    4. After approval, open NeoLock normally.
